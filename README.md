# sonnymorrow.com

Static portfolio site. No framework — plain HTML/CSS/JS generated by a small Node script.

## Edit content
All text, photos and project order live in `tools/content.mjs`. After editing, rebuild:

```bash
node tools/build.mjs
```

This regenerates `index.html`, `projects/*/index.html`, `404.html` and `CNAME`.
Don't edit those generated files by hand — changes will be overwritten.

## Preview locally
```bash
node tools/serve.mjs
```
Open the address it prints (normally http://127.0.0.1:4321). If that port is busy it picks the next free one.

## Add a project
1. Drop photos into `images/`.
2. Copy an existing entry in `tools/content.mjs`, give it a new `slug`, and fill it in.
3. Run the build.

## Deploy (GitHub Pages + custom domain)
1. Push this folder to a GitHub repo and enable Pages (Settings → Pages → Deploy from branch → `main` / root).
2. Once you own the domain, set `useCustomDomain: true` in `tools/content.mjs` and rebuild — this writes the `CNAME` file.
3. At your domain registrar, add DNS records:
   - `A` records for `@` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` for `www` → `<your-github-username>.github.io`
4. Back in Settings → Pages, tick **Enforce HTTPS** once the certificate is issued.
